# План: Исправление сохранения/чтения рабочей папки

## Диагностика проблемы

Пользователь сообщает: глобальные настройки (рабочая папка) не сохраняются при закрытии приложения, и не передаются в диалог "открыть проект" / "создать проект".

### Найденные баги

1. **Критический баг в `resolveWorkspacePath()`** — отсутствует `return` перед `try` блоком. Функция вычисляет значение, но не возвращает его, поэтому **всегда возвращает null**.

```kotlin
// Текущий код (НЕПРАВИЛЬНО):
fun resolveWorkspacePath(): Path? {
    if (Files.exists(workspacePath)) {
        Files.readString(workspacePath).takeIf { it.isNotBlank() }
            ?.let { Path.of(it) }
    } else null
}

// Правильный код:
fun resolveWorkspacePath(): Path? {
    return try {
        if (Files.exists(workspacePath)) {
            Files.readString(workspacePath).takeIf { it.isNotBlank() }
                ?.let { Path.of(it) }
        } else null
    } catch (_: IOException) {
        null
    }
}
```

2. **Lazy инициализация `configDir` и `workspacePath`** — может вызвать проблемы при多线程 доступе и усложняет отладку. Лучше использовать eager инициализацию.

## Решение

### Шаг 1: Исправить `resolveWorkspacePath()` — добавить `return`

**Файл:** `src/main/kotlin/com/pandakind/prompteditor/util/AppPaths.kt`

**Было:**
```kotlin
fun resolveWorkspacePath(): Path? {
    if (Files.exists(workspacePath)) {
        Files.readString(workspacePath).takeIf { it.isNotBlank() }
            ?.let { Path.of(it) }
    } else null
}
```

**Стало:**
```kotlin
fun resolveWorkspacePath(): Path? {
    return try {
        if (Files.exists(workspacePath)) {
            Files.readString(workspacePath).takeIf { it.isNotBlank() }
                ?.let { Path.of(it) }
        } else null
    } catch (_: IOException) {
        null
    }
}
```

### Шаг 2: Убрать `lazy` у `configDir` и `workspacePath`

**Было:**
```kotlin
val configDir: Path by lazy {
    val dir = resolveBaseDir().resolve(APP_DIR_NAME)
    Files.createDirectories(dir)
    dir
}

val workspacePath: Path by lazy {
    configDir.resolve("workspace_path.txt")
}
```

**Стало:**
```kotlin
val configDir: Path = run {
    val dir = resolveBaseDir().resolve(APP_DIR_NAME)
    Files.createDirectories(dir)
    dir
}

val workspacePath: Path = configDir.resolve("workspace_path.txt")
```

### Шаг 3: Обновить `ensureDirectories()`

**Было:**
```kotlin
fun ensureDirectories() {
    Files.createDirectories(configDir)
    Files.createDirectories(userDictPath.parent)
    // workspacePath is created lazily, no need to pre-create
}
```

**Стало:**
```kotlin
fun ensureDirectories() {
    // configDir and workspacePath are already initialized eagerly
    Files.createDirectories(configDir)
    Files.createDirectories(userDictPath.parent)
}
```

## Верификация

1. **`./gradlew build`** — все 52 теста должны пройти
2. **`./gradlew run`** — сценарий:
   - a) Настройки → Глобальные настройки → выбрать папку → OK
   - b) Проверить файл: `cat ~/.config/prompt_editor/workspace_path.txt`
   - c) Создать проект → диалог открывается в выбранной папке
   - d) Закрыть приложение
   - e) Открыть снова → Настройки → Глобальные настройки → путь должен быть заполнен
   - f) Создать проект → диалог открывается в выбранной папке
